Built for personal use.

My Fantasy Football Manager is an independent project maintained by the owner of the linked GitHub repository. The planned application will run locally on the owner's computer and use the Yahoo Fantasy Sports API, subject to Yahoo's approval and permitted access.

The initial scope is read-only access to the owner's authorized fantasy football data. This website describes the project; it does not provide a public sign-up service or connect visitors to Yahoo.

Privacy & data.

This landing page does not use analytics, advertising, sign-in forms, or application cookies. GitHub Pages hosts the site and may collect technical request information under GitHub's privacy statement.

The planned local application will store credentials and retrieved fantasy data locally, outside the public website and version control. It is intended for the owner's use, with no sale or public redistribution of private league data. Yahoo integration has not yet been implemented.
